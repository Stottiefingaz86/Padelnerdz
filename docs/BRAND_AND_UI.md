# Brand & UI — Padel Nerdz

## Brand personality
- energetic
- premium
- modern
- urban-sport
- social
- competitive but fun

## Visual direction
- clean modern app
- not a direct visual copy of WhatsApp
- premium dark / neutral foundation is acceptable
- strong accents for active states and match energy
- sharp iconography and polished interaction design

## Logo
Use the white Padel Nerdz wordmark with crown as primary lockup for dark surfaces.

### Asset references
See `branding/ASSET_PATHS.md`

## App icon direction
Recommended icon approach:
- use a simplified crown-led mark rather than full wordmark if legibility is poor at small sizes
- optional monogram variant: stylized `PN` with crown
- use bold contrast and simple silhouette
- must read clearly on iPhone and Android home screens

## UI principles
1. Chat should feel familiar, fast, and warm.
2. Play flows should be extremely clear.
3. Organiser controls should be powerful but not intimidating.
4. Discover should feel lively and local.
5. Motion should be subtle, premium, and native-feeling.

## Icons
- **Source of truth:** [Lucide](https://lucide.dev/icons) via `lucide-react-native`.
- **Wrapper:** `apps/mobile/components/Icon.tsx` — consistent size + stroke.
- Do not mix SF Symbols / Material / custom stroke drawings for chrome icons.

## Primary product areas
- Chats
- Play
- Discover
- Profile

## Suggestions for initial palette
This is a starting point only; refine in design.
- Background dark: #0F1115
- Surface: #171A20
- Elevated surface: #1E222A
- Primary text: #FFFFFF
- Secondary text: #B8BEC9
- Accent green: #6BFFB0 or similar energetic green
- Accent blue: #6DCBFF
- Warning: #FFB74D
- Error: #FF6E6E

## Typography direction
- clean geometric or neo-grotesque sans for UI
- logo remains expressive/brush-based
